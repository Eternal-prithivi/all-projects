# Zenith Demo Runbook

This runbook is for a final product demo or a handoff rehearsal. It keeps the flow simple and gives you the screenshots you should capture for later reuse.

## Goal

Show the full Zenith story in one short walkthrough:

1. Sign in.
2. Open the dashboard.
3. Review VM clustering.
4. Review storage and billing.
5. Show the admin view if needed.

## Before you start

- Start the backend and frontend.
- Make sure demo data is present.
- Use a test account with access to dashboard, storage, and billing views.

## Demo flow

### 1. Landing page

- Open the public home page.
- Point out the value proposition and multi-cloud focus.
- Capture screenshot: `demo-home-page.png`

### 2. Dashboard

- Sign in and land on the main dashboard.
- Show the high-level cost, resource, and security summary.
- Capture screenshot: `demo-dashboard-overview.png`

### 3. VM Cluster

- Open the VM cluster page.
- Show the topology cards, cluster summary, and health state.
- Capture screenshot: `demo-vm-cluster.png`

### 4. Storage

- Open the storage page.
- Show provider selection, file list, and optimization/recommendation workflow.
- Capture screenshot: `demo-storage-page.png`

### 5. Billing

- Open the billing page.
- Show current plan, next bill, and current month spend.
- Capture screenshot: `demo-billing-overview.png`

### 6. Admin view

- Open the admin dashboard if the demo account allows it.
- Show user counts, system health, and recent activity.
- Capture screenshot: `demo-admin-overview.png`

## Talking points

- Zenith reduces wasted cloud spend by showing cost and usage together.
- VM management stays visual and easy to scan.
- Storage decisions are guided by optimization and tiering.
- Billing and admin views keep the platform ready for real operations.
