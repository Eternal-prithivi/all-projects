# How to Run the Zenith Application

This project has two parts: a backend API and a frontend web application.
You must run both simultaneously in two separate terminal windows.

---
## Prerequisites

1.  Node.js (v20+ recommended)
2.  Python 3
3.  A `.env` file in the project's root directory containing the MONGO_CONNECTION_STRING.

---

NOTE:
Connect your mongodb to atlas cloud application cluster

## 1. Start the Backend Server

**Terminal Window 1**

1.  **Navigate to the project's root directory:**
    cd /path/to/CloudResourceOptimizationPlatform

2.  **Activate the Python virtual environment:**
    source venv/bin/activate

3.  **Navigate to the backend directory:**
    cd backend

4.  **Start the server:**
    uvicorn app.main:app --reload

==> The backend API is now running at http://localhost:8000

---
## 2. Start the Frontend Server

**Terminal Window 2**

1.  **Navigate to the project's root directory:**
    cd /path/to/CloudResourceOptimizationPlatform

2.  **Navigate to the frontend directory:**
    cd frontend

3.  **Start the server:**
    npm run dev

==> The frontend application is now running at http://localhost:5173
    Open http://localhost:5173 in your web browser.

3 terminal: for backround scanning of files and finding out any secret is exist

	celery -A app.celery_worker worker --loglevel=info

4 terminal: for keeping an alarm task every night for dynamic tiering after 30days

	celery -A app.celery_worker beat --loglevel=info

5 terminal: to check or to show the immediate results of what happens
	celery -A app.celery_worker call app.storage.tiering_tasks.run_storage_optimization
